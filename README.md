# Persatuan Taman Musytari Fasa 2

Portal komuniti rasmi penduduk Taman Musytari Fasa 2 dengan kemudahan bayaran yuran, sembang komuniti, aktiviti terbaru, dan profil peribadi.

## Features

- Community Portal
- Fee Payments
- Community Chat
- Latest Activities
- Personal Profiles

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Firebase (Firestore & Auth)
- Express
